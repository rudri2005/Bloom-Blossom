# 🌸 Bloom & Blossom – Flower Shop Website

Bloom & Blossom is a flower shop website designed to provide a simple, elegant, and user-friendly online shopping experience.

🌐 **Live Website:** [Visit Bloom & Blossom](https://bloomblossom-five.vercel.app/)

## ✨ Features

- Responsive floral-themed website design
- Homepage with attractive floral layout
- Dynamic product browsing from MySQL database
- Shopping cart interface
- Add-to-cart functionality
- Favorites functionality
- Contact Us section
- Form validation
- Contact form submissions stored in MySQL
- Smooth navigation and scrolling
- Mobile-friendly layout

## 🛠️ Technologies Used

**Frontend**
- HTML5

- JavaScript

**Backend**
- Java

**Database**
- MySQL

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/rudri2005/Bloom-Blossom.git
   ```

2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Configure MySQL and start the Java backend using Apache Tomcat.

## 🔧 Backend Integration

The backend is developed using Java Servlets, JDBC, and MySQL.

Implemented functionality:
- Fetching product data from MySQL and displaying it on the website.
- Saving Contact Us form submissions in MySQL.
- Connecting the frontend with Java backend APIs using Fetch API.
