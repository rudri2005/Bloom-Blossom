# 🌸 Bloom & Blossom – Flower Shop Website

Bloom & Blossom is a flower shop website designed to provide a simple, elegant, and user-friendly online shopping experience.

🌐 **Live Website:** [Visit Bloom & Blossom](https://bloomblossom-five.vercel.app/)

## ✨ Features

- Responsive floral-themed website design
- Homepage with attractive floral layout
- Product browsing section
- Shopping cart interface
- Add-to-cart functionality
- Contact Us section
- Form validation
- Smooth navigation and scrolling
- Mobile-friendly layout

## 🛠️ Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Java
- Java Servlets
- JDBC

**Database**
- MySQL

**Deployment**
- Vercel (Frontend)

**Development Tools**
- Visual Studio Code
- Apache Tomcat
- Git and GitHub

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/rudri2005/FlowerShopWebsite.git
   ```

2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.

## 🔧 Backend Development

The backend is being developed using Java Servlets and JDBC, with MySQL as the database.

Planned integration:
